# X-RAY - سیستم هوشمند رادیولوژی و ایکس‌ری

برنامه‌ای کاملاً پایتونی برای:
1. **بهبود کیفیت عکس** (Super-Resolution & Denoising)
2. **تشخیص دقیق بیماری** (AI Diagnosis)
3. **بازسازی سه‌بعدی** (3D Reconstruction)
4. **آموزش مدل** با عکس‌های رادیولوژی

## ساختار پروژه
- `requirements.txt`: بسته‌های مورد نیاز
- `app.py`: رابط کاربری (Streamlit)
- `models/diagnoser.py`: ماژول تشخیص بیماری
- `utils/enhancer.py`: ماژول بهبود کیفیت عکس
- `utils/reconstructor.py`: ماژول بازسازی سه‌بعدی
- `train.py`: اسکلت آموزش مدل
- `data/`: پوشه برای ذخیره عکس‌های ورودی
- `output/`: پوشه برای خروجی‌ها (عکس بهبود یافته، مدل سه‌بعدی)

## نحوه اجرا
1. نصب بسته‌ها:
   ```bash
   pip install -r requirements.txt
   ```
2. اجرای برنامه:
   ```bash
   streamlit run app.py
   ```

## ویژگی‌ها
- **بهبود کیفیت:** افزایش رزولوشن و حذف نویز از عکس‌های ایکس‌ری
- **تشخیص:** شناسایی بیماری‌ها با هوش مصنوعی (پنومونی، شکستگی، تومور و...)
- **سه‌بعدی‌سازی:** تبدیل عکس دوبعدی به مدل سه‌بعدی (Volume) برای تحلیل دقیق‌تر
- **آموزش:** امکان آموزش مدل با داده‌های جدید رادیولوژی
